# DearLive Reconstructed Master Animation + Audio Pack

## Important provenance
These are **reconstructed master-equivalent development assets**, manufactured from the supplied DearLive reference images and video. They are not the original proprietary source files from the original DearLive production project.

## Included
- Real GIF files reconstructed from supplied visual references.
- Real Lottie JSON animation files generated as editable vector-animation masters.
- Real WAV files generated from scratch for UI/game sound effects.

## Animation intent
- `card_deal`: card entrance/deal motion
- `chip_glow`: chip emphasis/pulse
- `timer_pulse`: countdown emphasis
- `coin_effect`: coin/reward burst
- `win_fireworks`: result/winner burst

## Integration rule
OpenCode should treat the supplied static asset ZIPs as visual masters and this package as the reconstructed animation/audio source layer. Do not claim these reconstructed files are the original DearLive production masters.
